# HR Analytics Dashboard

## About the Project

This repository contains the HR Analytics Dashboard project built using Tableau. The dashboard visualizes key employee metrics such as performance scores, engagement, satisfaction, work-life balance, and training outcomes. The goal of this project is to uncover valuable insights from the HR dataset that can aid in effective talent management and decision-making.

## Dataset Overview

The uploaded dataset contains detailed information about employees, their performance, training programs, and various HR-related metrics. Below are the columns included in the dataset:

- **Unnamed: 0**: Unique identifier (Index)
- **FirstName**: Employee's first name
- **LastName**: Employee's last name
- **StartDate**: The date the employee joined the organization
- **ExitDate**: The date the employee left the organization (if applicable)
- **Title**: Employee's job title
- **Supervisor**: Name of the employee's supervisor
- **ADEmail**: Email address of the employee
- **BusinessUnit**: Business unit in which the employee works
- **EmployeeStatus**: Current employment status
- **EmployeeType**: Type of employment (Full-time, Part-time, etc.)
- **PayZone**: Employee's pay zone
- **EmployeeClassificationType**: Employee classification (e.g., Permanent, Temporary)
- **TerminationType**: Type of termination (Voluntary, Involuntary)
- **TerminationDescription**: Further details of termination
- **DepartmentType**: Type of department (e.g., Sales, Marketing)
- **Division**: Employee’s division
- **DOB**: Date of birth
- **State**: Location of the employee (State)
- **JobFunctionDescription**: Description of the job function
- **GenderCode**: Gender of the employee
- **LocationCode**: Code for employee’s location
- **RaceDesc**: Race/ethnicity description
- **MaritalDesc**: Marital status description
- **Performance Score**: Employee’s performance score
- **Current Employee Rating**: Employee’s current performance rating
- **Employee ID**: Unique employee identifier
- **Survey Date**: Date the employee took the survey
- **Engagement Score**: Employee engagement score
- **Satisfaction Score**: Employee satisfaction score
- **Work-Life Balance Score**: Employee work-life balance score
- **Training Date**: Date the employee participated in training
- **Training Program Name**: Name of the training program
- **Training Type**: Type of training program
- **Training Outcome**: Outcome of the training (e.g., Completed, Incomplete)
- **Location**: Location of the employee
- **Trainer**: Name of the trainer conducting the session
- **Training Duration (Days)**: Duration of the training in days
- **Training Cost**: Cost of the training program

## Features of the Dashboard

The dashboard includes the following key features:
- **Employee Performance**: Visualize employee performance scores, trends over time, and departmental performance comparison.
- **Engagement and Satisfaction**: Display engagement and satisfaction scores to assess employee happiness.
- **Work-Life Balance**: Analyze employee work-life balance across different departments and locations.
- **Training Impact**: View insights into training program effectiveness, including cost vs. outcomes and training duration impact.
